## 时间段与观察

| 时间（近似） | 实际可见 | 实现要求 |
| --- | --- | --- |
| 0～7s | 浅灰偏紫整片键盘、左上品牌、右上灰色圆形取消；中央黑色圆形真实波形，淡灰环；下方“再次点击以完成”，左下地球键 | 录音视图收起无关编辑键，波形绑定真实音量；点按完成、取消独立；无真实采集时不伪造波形 |
| 8～10s | 中央收缩为横向深色 Thinking 胶囊，内部浅色扫动；保留取消和地球键 | processing 状态、取消、减少动态效果；不以定时器假装返回结果 |
| 11～12s、22～26s | 空闲页品牌＋右上语音／EN／拼白色胶囊；中央“点击说话”与黑色横向麦克风；左右有撤销／帮写、删除／@；下方白色换行胶囊 | 简洁一致的空闲控件；Return／delete／@作用于真实输入目标，撤销只在可安全撤销时出现／可用；不借参考增加不受控编辑 |
| 13～18s | “帮我写”页；左下较小黑色音量圆，右侧“描述要写的内容／再次点击以完成”；右上取消 | 提示词驱动帮写，不是选区润色；请求真正可用后才执行；生成预览／受控插入保留 |
| 19～21s | 帮写处理胶囊 | 真实任务处理状态，失败不伪造文本或插入 |
| 27s | 顶部弧形目标选择，提示“向上滑动以选择”，下方“松开以取消”；三个示例目标 | 长按进入选择态，上滑命中已配置目标；不是所有按住说话松开都取消；使用真实目标列表，不把视频示例语言写死 |
| 28s | 右侧英语目标黑底选中，提示“释放以翻译”，取消区域 | 有效目标释放提交意图；无目标释放取消；越界／中断规则可测 |
