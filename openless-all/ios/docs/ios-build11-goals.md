# Build 11：键盘体验目标与实现

参考：用户提供的 `IMG_1751.jpg`、`IMG_1752.jpg` 和 `ScreenRecording_10-21-2026 16-58-04_1.MP4`（169.16 秒）。录屏前段展示 Typeless 的中文候选 → 确认原始字母 → 再次发送；后段展示 OpenLess 的尺寸、录音波形、翻译白条与 processing 文案。沿用 Build 10 的 PiP/音频生命周期，本轮不改变其准入或路由。

| 反馈 | 实现 |
|---|---|
| 键盘太大、希望自定义 | 默认四行内容区从 232pt 改为 208pt，接近参考截图；设置→键盘→键盘高度提供 90%–120% 调节及恢复推荐大小。主 App 保存并通过现有共享偏好同步，横屏使用更低的独立基准。 |
| 润色模式重开变原文 | 使用键盘私有 UserDefaults 独立保存风格 ID，扩展重新创建时读取。普通设置/旧主 App 快照不覆盖该选择；不可用风格显示不可用，不静默切回原文。 |
| 英文输入不应直接出现在候选栏 | 移除人工添加的原文候选按钮，保持 Rime 候选。组合期间第一次 Return 提交准确 rawInput，不发送；组合清空后第二次 Return 执行宿主换行/发送动作。 |
| 语音页缺少 @ | @ 始终占独立空闲编辑位置，不再被撤销替换；有可安全撤销的听写结果时，长按 @ 可选择撤销。删除放在右侧上方，减少底部拥挤。 |
| 输入法后端是什么 | 拼音组合/候选为 Rime；布局/手势为 KeyboardKit 9.9.0；项目提供本地联想与词库；默认语音识别为 SenseVoice Small。本轮不替换引擎。 |
| 红色录音与波形不明显 | 键盘录音圆由 72pt 改为 96pt，白色波形加粗；真实 RMS 按语音常见 dB 范围映射，低音量也能看清波形。无音量时不伪造跳动；尊重减少动态效果。 |
| 翻译白条难看 | 去掉实色背景，翻译状态放在“再次点击以完成”下方；两行同字体、同 secondaryLabel 灰色。 |
| 处理中/分析统一文案 | 语音 processing 标签统一为小写 `thinking`，覆盖共享按钮、主应用状态及激活页；准备和等待插入仍表达各自状态。 |
| 键盘整体体验 | 顶部模式改为波形图标/EN/拼，简化选中背景；中文主操作键缺少库内文案时显示发送/回车图标；空闲麦克风使用清晰胶囊和上方提示，收敛工具尺寸与布局。 |

## 状态与兼容

- `KeyboardPreferences.keyboardScale` 为新增可选解码字段，旧数据默认 100%；限制异常/非有限数值，不让键盘塌陷或异常增高。
- 高度在主应用设置；与其他共享偏好一样，扩展同步需要“允许完全访问”。基础打字和本地润色选择记忆不新增网络依赖。
- 原文从 Rime `get_input` 读取，保留 `v`、用户输入的分隔符等，不从格式化 preedit 反推。点击中文候选、空格选词与原始字母确认是不同操作。
- 录音波形只改变显示映射，不更改麦克风增益、PCM 或识别输入。视觉测试使用明确标识的模拟 RMS，不能作为实际开麦证据。

## 验收

1. 设置高度为 90% 后重开应用，数值保留；恢复推荐为 100%，键盘整体低于 Build 10。
2. 选择润色风格，收起/重开及扩展重启后仍保留；主动选原文后才清除。
3. 拼音输入 openless，候选栏不额外插英文项；第一次确认输入 openless，第二次执行宿主动作；nihao 点击“你好”仍为中文。
4. 语音页输入 @，听写结束后 @ 仍存在；需要撤销时长按 @。
5. 录音时能明显辨认圆形与波形；翻译说明在完成提示下面，无白条；结束后显示 thinking。
